# ShopSmart AI Pro

A polished, Vercel-ready AI shopping discovery experience.

## Functional now
- Product search
- Category filters
- AI Picks mode
- AI shortlist interaction
- Product ratings and discount calculations
- Side-by-side comparison selection (up to 3 products)
- Add/remove cart items
- Automatic cart total
- Checkout confirmation simulation
- Responsive mobile/desktop UI
- No external API keys required

## Deploy
Import this repository into Vercel. It will detect Next.js automatically. No environment variables are required.

## Local
```bash
npm install
npm run dev
```

Live commerce integrations such as payment processing, inventory, authentication, merchant feeds and persistent orders can be connected later without replacing the UI.
